## 📋 Sobre o Projeto

Este é o meu portfólio profissional e landing page institucional, 
desenvolvido para apresentar minhas habilidades como **Desenvolvedora Web e Analista de Sistemas**.
O projeto foi construído do zero focando em alta performance, design responsivo (Mobile First), uma interface moderna com modo escuro nativo e 
ótimas práticas de SEO para mecanismos de busca.

🔗 **Acesse o site oficial:** [lorranevelosodevweb.com.br](https://lorranevelosodevweb.com.br)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as ferramentas mais modernas e eficientes do ecossistema JavaScript:

* **[React](https://reactjs.org/)** — Biblioteca para construção da interface baseada em componentes reutilizáveis.
* **[TypeScript](https://www.typescriptlang.org/)** — Tipagem estática para garantir maior segurança, manutenção e qualidade de código.
* **[Vite](https://vitejs.dev/)** — Build tool ultra-rápido para o ambiente de desenvolvimento.
* **[Tailwind CSS](https://tailwindcss.com/)** — Framework utilitário de CSS para estilização rápida, fluida e totalmente responsiva.
* **[Lucide React](https://lucide.dev/)** — Pacote de ícones limpos e modernos de alta qualidade.

## ⚙️ Arquitetura e Recursos

* **Componentização Limpa:** Código legível, modular e escalável.
* **SEO Otimizado:** Configuração de meta tags estruturadas para melhor ranqueamento no Google Search Console.
* **Deploy Contínuo (CI/CD):** Integração automatizada entre o GitHub e a **Vercel** para atualizações em tempo real a cada commit na branch principal.
